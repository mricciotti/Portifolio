## Sobre o projeto

Uma aplicação de página única, em português, com apresentação pessoal, experiência profissional e acadêmica, projetos, tecnologias e contato.

O visual combina fundo escuro, cartões translúcidos e detalhes em ciano e violeta. A animação orbital em SVG complementa a apresentação, com respeito à preferência por movimento reduzido.

## Tecnologias

O código do portfólio é escrito em **JavaScript**, com:

- **React 18** para componentes e interações.
- **Vite** para desenvolvimento e build.
- **Tailwind CSS** para estilos, responsividade e tokens visuais.
- **React Router** para a estrutura da aplicação.
- **React Icons** para ícones.
- **Playwright e axe-core** para testes de navegador e verificações de acessibilidade.

## Experiência de uso

- Navegação fixa com destaque da seção visível e menu adaptado ao celular.
- Links para pular ao conteúdo, foco visível e campos de formulário com rótulos.
- Projetos com detalhes acessíveis por mouse, teclado ou toque.
- Imagens em WebP e fontes hospedadas no próprio projeto.
- Animações que respeitam `prefers-reduced-motion`.
- Formulário que prepara a mensagem no aplicativo de e-mail, além da opção de copiar o endereço de contato.

## Executar localmente

Com Node.js e npm instalados:

```sh
git clone https://github.com/mricciotti/Portifolio.git
cd Portifolio/portifolio
npm ci
npm run dev
```

Abra o endereço exibido no terminal. Por padrão, o Vite utiliza `http://localhost:5173`.

As instruções de testes, organização do código e publicação estão no [guia de desenvolvimento](./portifolio/README.md).
