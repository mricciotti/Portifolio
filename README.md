# Portfólio de Matheus Ricciotti

Versão combinada de Astra e Sonnet, desenvolvida na branch `new`.

A aplicação está em [portifolio](./portifolio). Veja [as instruções de execução e validação](./portifolio/README.md).

## Composição escolhida

| Seção | Versão |
| --- | --- |
| Header | Astra |
| Início | Astra, com a foto pessoal |
| Sobre | Astra, com a animação orbital |
| Experiência | Sonnet, com instituição acima do cargo/curso e etiquetas Experiência/Formação |
| Projetos | Sonnet, com imagens proporcionais e descrições acessíveis por foco e toque |
| Skills | Sonnet |
| Contato e footer | Astra |
| Fundo e tokens de base | Astra |

As versões de referência não são modificadas por esta integração.
